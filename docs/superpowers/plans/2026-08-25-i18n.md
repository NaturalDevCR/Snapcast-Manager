**Goal:** Add EN/ES internationalization to the client (vue-i18n, a language switcher, persisted locale) and extract the strings of a pilot set of views (Login, Setup, Onboarding, Layout, Dashboard) as a proven, repeatable pattern.

**Architecture:** `vue-i18n` in Composition API mode, one namespaced JSON file pair per view under `client/src/locales/{en,es}/`, locale detection/persistence mirroring `useUIStore`'s existing theme-persistence pattern, a switcher in `Layout.vue`.

**Tech Stack:** Vue 3.5 `<script setup>`, `vue-i18n`, Pinia, Vite 7, Vitest + `@vue/test-utils`.

## Global Constraints

- Client-side UI strings only — server-emitted error messages stay in English (spec §"Non-goals").
- This plan's rollout is Login.vue, Setup.vue, Onboarding.vue, Layout.vue, Dashboard.vue only — every other view is explicit, disclosed follow-up work, not silently dropped scope (spec §"Rollout scope").
- Existing Vitest smoke tests must keep passing with their current English-text assertions unchanged — achieved by mounting with the i18n plugin defaulted to `'en'` in the shared test helper (spec §"Testing").
- Locale override persists the same way theme does today: `useUIStore()` → `localStorage` (spec §"Library & locale mechanics").
- Translation keys are FLAT per namespace file (not deeply nested by section) — confirmed concretely against `Login.vue`'s actual string inventory in Task 3 below; every later task's view follows the same flat-per-namespace convention.

- [ ] **Step 5: Implement `client/src/i18n.ts`**

```typescript
import { createI18n } from 'vue-i18n';
import enCommon from './locales/en/common.json';
import esCommon from './locales/es/common.json';

export type SupportedLocale = 'en' | 'es';
export const SUPPORTED_LOCALES: SupportedLocale[] = ['en', 'es'];

export function detectDefaultLocale(): SupportedLocale {
  const lang = navigator.language?.toLowerCase() ?? '';
  if (lang.startsWith('es')) return 'es';
  return 'en';
}

const storedLocale = localStorage.getItem('locale') as SupportedLocale | null;
const initialLocale: SupportedLocale =
  storedLocale && SUPPORTED_LOCALES.includes(storedLocale) ? storedLocale : detectDefaultLocale();

export const i18n = createI18n({
  legacy: false,
  locale: initialLocale,
  fallbackLocale: 'en',
  messages: {
    en: { common: enCommon },
    es: { common: esCommon },
  },
});

export default i18n;
```
